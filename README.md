# JEE 30-Day Sprint

A responsive, dependency-free JEE Main study calendar for Physics, Chemistry and Mathematics.

## Features

- 30-day calendar with real dates based on a selectable start date
- Daily checklist for all three subjects
- Completion percentage, completed task count and fully completed days
- Previous/next day navigation and a calendar day picker
- Automatically saves checkmarks in the browser's local storage
- Mobile-friendly layout; no build step or external dependencies

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Open this repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)` folder, then save.
5. Wait for GitHub Pages to publish the site. The URL will be shown in the Pages settings and will normally be:
   `https://inviswizard.github.io/Jee/`

## Progress and privacy

Progress is stored only in the browser and device where the site is used. It does not sync between devices or browsers. Clearing browser site data will clear saved checkmarks. Use the same browser on the same device each day to keep your progress.

The plan is a study-priority guide, not an official NTA prediction. Adjust it to your coaching progress and the current official syllabus.
